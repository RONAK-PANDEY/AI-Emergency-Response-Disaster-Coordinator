PLATFORM ARCHITECTURE:
--------------------------------------------------------------------------------
1. Citizen Reporter Portal:     http://localhost:5174
2. Government Officer Portal:   http://localhost:5175
3. Shared Backend & AI Engine:  http://localhost:8000
4. Interactive Swagger Docs:    http://localhost:8000/docs


METHOD 1: 1-CLICK LAUNCHERS (DOUBLE-CLICK IN WINDOWS EXPLORER)
--------------------------------------------------------------------------------
[ROOT FOLDER]
- start_all.bat
  Starts EVERYTHING (Backend + Citizen Portal + Officer Portal).
  Opens both portals in your browser.

- start_reporter_portal.bat
  Starts the Citizen Portal stack (Backend :8000 + Citizen UI :5174).

- start_officer_portal.bat
  Starts the Government Officer Portal stack (Backend :8000 + Officer UI :5175).

- start_backend.bat
  Starts only the shared FastAPI backend.

[PORTAL FOLDERS]
- reporter-portal\start_all.bat (Starts Backend + Citizen Portal)
- officer-portal\start_all.bat  (Starts Backend + Officer Portal)


METHOD 2: MANUAL TERMINAL STARTUP
--------------------------------------------------------------------------------
[1. SHARED BACKEND (Port 8000)]
cd "my-hackathon-project\backend"
venv\Scripts\activate.bat
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

[2. CITIZEN REPORTER PORTAL (Port 5174)]
cd "reporter-portal"
node ./node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5174

[3. GOVERNMENT OFFICER PORTAL (Port 5175)]
cd "officer-portal"
node ./node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5175
