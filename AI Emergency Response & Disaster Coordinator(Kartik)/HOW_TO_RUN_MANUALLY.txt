AI Emergency Response & Disaster Coordinator - Startup Guide
========================================================================

METHOD 1: 1-CLICK LAUNCH (RECOMMENDED)
------------------------------------------------------------------------
In this directory, simply double-click:

  - start_all.bat       -> Starts BOTH Backend + Frontend and opens browser
  - start_backend.bat   -> Starts only the Backend (port 8000)
  - start_frontend.bat  -> Starts only the Frontend (port 5173)


METHOD 2: MANUAL RUN (TERMINAL / POWERSHELL)
------------------------------------------------------------------------
Step 1: Open Terminal 1 (Backend)
  Run:
    cd "c:\Users\karti\Desktop\AI Emergency Response & Disaster Coordinator\my-hackathon-project\backend"
    & "..\..\.venv\Scripts\python.exe" -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

Step 2: Open Terminal 2 (Frontend)
  Run:
    cd "c:\Users\karti\Desktop\AI Emergency Response & Disaster Coordinator\my-hackathon-project\frontend"
    node ./node_modules/vite/bin/vite.js --host 0.0.0.0 --port 5173

Step 3: Open in Chrome / Browser
  Frontend App:  http://localhost:5173
  API Docs:      http://127.0.0.1:8000/docs


ADDING AN OPENAI API KEY IN THE FUTURE (OPTIONAL)
------------------------------------------------------------------------
1. In "my-hackathon-project\backend", create a file named ".env"
2. Write:
   OPENAI_API_KEY=your_key_here
3. Restart the backend server.
